# 🌉 桥梁记录助手（Record）

面向桥梁现场巡检/施工记录的 Android 应用，支持按项目管理病害记录、工作记录和安全记录，并可一键导出分享文档。

## ✨ 软件能做什么

- 📁 项目管理：新建、重命名、删除项目，按项目隔离数据。
- 🧱 病害记录：录入构件编号、病害类型、病害位置、定量描述，并绑定拍照图片。
- 📷 工作/安全记录：支持批量拍照、关键词补充描述、记录筛选与批量删除。
- 📚 词库管理：可维护构件编号、病害类型、纵/横向参照点；支持 Excel 模板下载与词库导入。
- 📤 文档导出：
  - 病害记录导出为 Excel（`.xlsx`）。
  - 工作记录/安全记录导出为 Word（`.docx`）。
  - 导出后可直接通过系统“分享”发送到微信、QQ、邮件等应用。

## ⚙️ 运行环境

- Android 8.0 及以上（minSdk 26）。
- 建议设备具备摄像头（无摄像头也可安装，但拍照能力受限）。

## 📦 安装方式（使用者）

### 方式一：📱 直接安装 APK

如果你已经拿到安装包（例如 `Record-arm64-debug.apk`）：

1. 将 APK 拷贝到手机。
2. 在手机上打开 APK 进行安装。
3. 首次安装如提示“未知来源安装”，按系统引导允许后重试。

### 方式二：🛠️ 让开发者打包

如果你是从源码获得本项目，请让开发者构建并提供 APK 包给你安装。

## 🚀 快速上手

### 1. 🏗️ 创建项目

1. 打开应用进入“项目”页。
2. 点击右下角 `+` 新建项目。
3. 点击项目卡片进入项目详情。

### 2. 📝 录入病害记录

1. 在项目详情底部切到“病害记录”。
2. 点击右下角 `+` 新增病害。
3. 依次填写：
   - 构件编号
   - 病害类型
   - 病害位置
   - 定量参数（部分病害类型会自动生成定量描述）
4. 点击相机按钮拍照并绑定照片。
5. 点击“保存并继续”或“保存返回”。

### 3. 👷 录入工作/安全记录

1. 在项目详情底部切到“工作记录”或“安全记录”。
2. 点击右下角拍照按钮。
3. 首次会要求输入记录描述；之后可连续拍照组成一组记录。
4. 可点关键词快速补充描述，完成后保存。

### 4. ✅ 批量选择、删除与导出

- 病害记录支持多选后“分享已选”或“删除已选”。
- 工作/安全记录支持按组多选后导出或删除。
- 顶部分享按钮可导出当前栏目全部内容。

## 🧩 词库管理（建议先配置）

入口：项目列表右上角“设置”图标 -> 词库管理。

可管理四类词库：

- 构件编号
- 病害类型
- 纵向位置参照点
- 横向位置参照点

支持能力：

- 手工新增、启用/停用、删除（默认词条不可删除）。
- 下载 Excel 模板。
- 按模板导入 Excel 词库，自动跳过重复词条。

## 📄 导出文件说明

- 病害记录：导出为 Excel，包含构件编号、病害类型、病害位置、定量描述、照片编号。
- 工作/安全记录：导出为 Word，含照片与描述排版。
- 文件由系统分享，通常会保存在目标应用或聊天附件中。

## 💾 数据与存储说明

- 项目、病害记录、词库等数据保存在本机数据库（离线可用）。
- 拍摄图片保存于应用私有/媒体目录；删除记录时会同步删除关联图片文件。
- 卸载应用会导致本地数据丢失，请及时导出重要资料。

## ❓ 常见问题

### 1) 为什么无法导出？

- 请确认当前栏目有可导出的记录。
- 确认手机有可用分享目标应用（如微信、邮箱）。
- 重试仍失败时，建议先重启应用后再次导出。

### 2) 为什么拍照后没有绑定到记录？

- 请确认拍照完成后返回应用，而不是中途取消。
- 如设备存储权限或系统媒体写入受限，可能导致保存失败。

### 3) 删除项目会怎样？

- 该项目下病害记录会被一并删除，请谨慎操作。
